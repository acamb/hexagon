# M2

## 1 - First time wizard
L'applicazione viene avviata senza github client id / secret e genera una password temporanea stampata nei log.
Una pagina di first time wizard chiede quella password ed una volta inserita e' possibile inserire client id / secret / username abilitati che vengono salvati nel db.

## 2 - Configurazioni server
Nuova pagina settings dove impostare le configurazioni dell'applicazione:
 - porta
 - client id / secret
 - username github abilitati

## 3 - Supporto a build complesse
Deve essere possibile specificare un compose ed un docker file (modalita' "avanzata"), oltre al modo attuale in cui si specifica solo un docker file/immagine (modalita' "semplice").
Nella modalita' semplice deve essere possibili indicare le porte da pubblicare (facendo vedere all'utente container port / container host)

## 4 - Multi account
Deve essere possibile avere piu' account di claude configurati e se c'e' ne' piu' di uno deve essere possibile sceglierlo in fase di creazione o allo start di una sessione dopo che e' stata messa in stop.
